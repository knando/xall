01 — Fundamentos

Tipos Primitivos

Pense em cada variável como uma caixa de tamanho específico. Uma caixa de sapato não guarda um sofá: cada tipo tem tamanho e tipo de conteúdo fixos.
Tipos primitivos são predefinidos pela linguagem e nomeados por palavra reservada.

byte
A menor caixa. Guarda números inteiros de -128 a 127.
short
Pouco maior que o byte, para inteiros de tamanho médio.
int
A caixa "padrão" para números inteiros e mais usada.
long
Usada quando o número inteiro é gigante demais para o int.
float
Guarda números reais (casas decimais) com precisão simples. Termina com f: 3.5f.
double
Guarda números reais com mais precisão. Padrão para decimais em Java.
char
Post-it com única letra ou símbolo entre aspas simples: 'A'.
boolean
Um interruptor, apenas dois estados: true (ligado) ou false (desligado).
Tipo Tamanho Faixa / Conteúdo Exemplo
byte 1 byte -128 a 127 byte idade = 25;
int 4 bytes ~ -2 bi a 2 bi int ano = 2026;
long 8 bytes números enormes long pop = 8000000000L;
double 8 bytes decimais precisos double pi = 3.14159;
char 2 bytes 1 caractere char letra = 'J';
boolean 1 bit* true ou false boolean ativo = true;
Tipos.java 
public class Tipos {
    public static void main(String[] args) {

        // ── Declaração e inicialização ──
        int     idade = 20;
        double  nota  = 8.5;
        char    letra = 'J';
        boolean ativo = true;

        // ── Exibir valores ──
        System.out.println("Idade: " + idade);
        System.out.println("Nota: " + nota);

        // ── Casting: trocar de caixa ──
        double preco = 19.9;
        int precoInteiro = (int) preco; // vira 19, perde o resto
        System.out.println(precoInteiro);
    }
}
💡
Casting é trocar de caixa. Colocar double dentro de int é como fazer suco de fruta. As cascas não fazem parte e são descartadas (casas decimais cortadas ao invés de arredondar o número).
02 — Texto

Strings

Uma String é como uma corrente de aço e cada elo é uma letra. Strings não podem ser alteradas após sua criação.

String
Um texto, sempre entre aspas duplas: "Olá". Por trás, é uma sequência de char.
Imutabilidade
Uma String nunca muda depois de criada. "Editar" cria uma corrente nova e não modifica a antiga.
Concatenação
Juntar textos com +. Como soldar duas correntes pelas pontas.
.equals()
Compara o conteúdo da String. É assim que se compara texto em Java e nunca se usa ==.
.length()
Conta quantos elos (caracteres) tem a corrente.
.charAt() / .substring()
Pega um caractere específico ou pedaço do texto.
Strings.java 
public class Strings {
    public static void main(String[] args) {

        String nome = "Java";
        String sobrenome = "Básico";

        // ── Concatenação ──
        String completo = nome + " " + sobrenome;
        System.out.println(completo); // Java Básico

        // ── Métodos úteis ──
        System.out.println(completo.length());       // 11
        System.out.println(completo.toUpperCase()); // JAVA BÁSICO
        System.out.println(completo.charAt(0));     // J
        System.out.println(completo.substring(0,4)); // Java

        // ── Comparação correta ──
        String a = "Java";
        String b = new String("Java");
        System.out.println(a == b);        // false — colares diferentes
        System.out.println(a.equals(b)); // true — mesmo conteúdo
    }
}
⚠️
== e equals(): == pergunta "é a mesma corrente na memória?". equals() pergunta "as correntes são iguais?". Para texto, sempre use equals().
03 — Coleções

Arrays (Vetores)

Um array é um armário de gavetas numeradas, todas do mesmo tipo. A primeira gaveta é sempre a gaveta 0.
Arrays podem ser declarados como em C porém isto não é recomendado pelas convenções da linguagem Java.

Declaração
Cria o armário: int[] numeros = new int[5];: 5 gavetas vazias (iniciadas com zero).
Índice
O número da gaveta. Começa em 0 e vai até tamanho - 1.
Tamanho fixo
Depois de criado, o número de gavetas não muda. Para mais gavetas se cria um array novo.
.length
Propriedade (sem parênteses!) que conta quantas posições (gavetas) o array tem.
ArrayIndexOutOfBounds
Erro ao tentar abrir uma gaveta que não existe, como a gaveta 5 num armário de 5 (0 a 4).
for-each
Percorre todas as gavetas sem se preocupar com o número de cada uma.

Arrays.java 
public class Arrays {
    public static void main(String[] args) {

        // ── Criando e preenchendo o armário ──
        int[] numeros = {10, 25, 7, 42, 3};

        // ── Acessando uma gaveta pelo índice ──
        System.out.println(numeros[0]); // 10 — a primeira gaveta

        // ── Percorrendo com for tradicional ──
        for (int i = 0; i < numeros.length; i++) {
            System.out.println("Gaveta " + i + ": " + numeros[i]);
        }

        // ── Percorrendo com for-each ──
        for (int n : numeros) {
            System.out.print(n + " "); // 10 25 7 42 3
        }
    }
}
for (int i = 0; i < numeros.length; i++)
i = 00 < 5 ✓abre gaveta [0] → 10
i = 11 < 5 ✓abre gaveta [1] → 25
i = 22 < 5 ✓abre gaveta [2] → 7
i = 33 < 5 ✓abre gaveta [3] → 42
i = 44 < 5 ✓abre gaveta [4] → 3
i = 55 < 5 ✗ → PARA (gaveta 5 não existe!)
🔴
Cuidado com o limite — Um armário de 5 gavetas tem índices de 0 a 4. Tentar acessar numeros[5] quebra o programa com ArrayIndexOutOfBoundsException.
04 — Comunicação

Entrada e Saída

Um programa precisa falar com o usuário. Duas formas comuns são a conversa por texto no terminal e por janelas pop-up.

System.out.println
Fala com o usuário pelo terminal e adiciona quebra de linha.
System.out.printf
Fala formatando o texto como em C: %d para inteiro, %s para texto.
Scanner
O "microfone" que escuta o que o usuário digita no terminal.
JOptionPane
Cria janelas pop-up de mensagem ou pergunta. São um tipo de JDialog.
JDialog
Janela genérica do Swing. JOptionPane é uma versão simplificada para uso.
import
Para usar Scanner ou JOptionPane é preciso "chamar a ferramenta" com import no topo do arquivo.

Terminal - conversa por texto

EntradaTerminal.java 
import java.util.Scanner;

public class EntradaTerminal {
    public static void main(String[] args) {

        Scanner leitor = new Scanner(System.in); // como fgets(txt, sizeof(txt), stdin)

        System.out.print("Qual seu nome? ");
        String nome = leitor.nextLine();  // lê uma linha de texto
        // String nome = IO.readLn(); -> teria efeito similar

        System.out.print("Qual sua idade? ");
        int idade = leitor.nextInt();   // lê um número inteiro
        // int idade = Integer.parseInt(IO.readLn()); -> necessita conversão

        System.out.printf("Olá %s, você tem %d anos!\n", nome, idade);

        leitor.close(); // desliga o microfone
    }
}

Janelas - conversa por pop-up

O JOptionPane permite interação com janelas que aparecem na tela.

EntradaJanela.java 
import javax.swing.JOptionPane;

public class EntradaJanela {
    public static void main(String[] args) {

        // ── Pergunta numa janela pop-up ──
        String nome = JOptionPane.showInputDialog("Qual seu nome?");

        // ── Entrada de texto vira número ──
        String textoIdade = JOptionPane.showInputDialog("Qual sua idade?");
        int idade = Integer.parseInt(textoIdade); // mesma conversão de IO.readLn()

        // ── Mostra mensagem em janela ──
        JOptionPane.showMessageDialog(null, "Olá " + nome + ", você tem " + idade + " anos!");
    }
}
💡
Por que Integer.parseInt? Estas entradas recebem String (texto puro). parseInt faz casting de texto para int.
⚠️
JOptionPane vs JDialog — JOptionPane é um atalho: já vem com botões e caixa de texto prontos. JDialog é a janela "crua", usada quando você quer montar sua própria janela do zero, com seus próprios botões e campos.
05 — Pratique

Exercícios

A melhor forma de aprender é codando. Tente resolver cada exercício antes de ver a dica!

EX 01 Caixinhas Certas
  • Crie variáveis: um int para idade, um double para altura e um char para a inicial do nome.
  • Exiba os três valores com System.out.println.
  • Faça um casting do double da altura para int e veja o que acontece.
💡 Dica: casting é (int) minhaVariavelDouble;
EX 02 Corrente de Letras
  • Guarde seu nome completo numa String.
  • Exiba quantidade de letras com .length().
  • Exiba a primeira letra com .charAt(0).
  • Exiba o nome todo em maiúsculas com .toUpperCase().
💡 Dica: espaços no nome também são caracteres.
EX 03 Armário de Notas
  • Crie um array double[] com 5 notas.
  • Percorra o array com um for tradicional, somando as notas.
  • Divida a soma por notas.length para achar a média.
💡 Dica: cuidado ao dividir pois dividir dois int fará o Java descartar as casas decimais.
EX 04 Entrevista no Terminal
  • Use Scanner ou IO para perguntar nome, idade e cidade do usuário.
  • Guarde os valores em variáveis com tipo correto.
  • Exiba um resumo formatado com System.out.printf.
💡 Dica: depois de ler um número com nextInt(), use leitor.nextLine() uma vez a mais para "limpar" o Enter antes de ler texto.
EX 05 Calculadora em Janelas
  • Use JOptionPane.showInputDialog para pedir dois números.
  • Converta o texto de cada um para double com Double.parseDouble.
  • Some os dois valores (ou peça outra operação ao usuário).
  • Mostre o resultado com JOptionPane.showMessageDialog.
💡 Dica: se o usuário digitar letras ao invés de números o programa quebrará. Erro comum de conversão de dados.

Gabarito — Exercício 03 (média)

Media.java 
public class Media {
    public static void main(String[] args) {

        double[] notas = {7.5, 8.0, 6.5, 9.0, 10.0};
        double soma = 0;

        for (int i = 0; i < notas.length; i++) {
            soma += notas[i];
        }

        double media = soma / notas.length;
        System.out.printf("Média: %.2f\n", media); // Média: 8.20
    }
}
